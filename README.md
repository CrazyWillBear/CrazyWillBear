# Hi, I'm [Will C](https://www.williamchastain.com) 👋

I'm 21, studying Computer Science & Engineering (minor in Philosophy) at Bucknell University. I work on applied LLM engineering: building AI agents and multi-agent (swarm) systems. Off the screen, I'm a philosophy person. I think a lot about ethics, consciousness, metaphysics, and care deeply about building capable systems responsibly.

## What I'm building

- **[Cogito](https://cogito.williamchastain.com)** (live): a full-stack AI philosophy research agent. It searches a 1.7M-embedding corpus of philosophy texts through six MCP research servers and synthesizes cited, evidence-backed answers.
- **[Chief](https://github.com/CrazyWillBear/chief)**: a personal agent that runs on your own machine and can edit its own code. I call it the "Arch Linux of agents".
- **[my-dotclaude](https://github.com/CrazyWillBear/my-dotclaude)**: my Claude Code setup, including an autonomous software development swarm.

## Other things I've made

- **[blogman](https://github.com/CrazyWillBear/blogman)** (powers [my blog](https://blog.williamchastain.com)): a Markdown-driven blog engine that turns posts into a live site automatically.
- **[Sosa](https://github.com/CrazyWillBear/Sosa)**: a hand-made LangGraph-based AI agent with universal memory, auto-injected project docs, external tools, and a persistent personality.
